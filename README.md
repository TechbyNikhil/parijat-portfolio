# Parijat Yadav (Mayur Yadav) — Personal Portfolio

A modern personal portfolio website built for **Parijat Yadav** (also known as **Mayur Yadav**), a BCA Artificial Intelligence student at Invertis University, aspiring developer, and professional with experience in sales, marketing, CRM, and event hosting.

![Portfolio Preview](./public/parijat-photo.jpg)

## ⚡ Tech Stack

* **Core**: React 18, Vite
* **Styling**: Tailwind CSS, Custom Glassmorphism System
* **Animations**: Framer Motion
* **Icons**: Lucide React
* **Micro-interactions**: Canvas Confetti, HTML5 Canvas Particle Field

## 🎨 Design System

* **Background**: `#080B14`
* **Secondary Background**: `#111827`
* **Primary Accent**: `#6366F1` (Indigo)
* **Secondary Accent**: `#22D3EE` (Cyan)
* **Main Text**: `#F8FAFC`
* **Secondary Text**: `#94A3B8`
* **Typography**: Plus Jakarta Sans & JetBrains Mono

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Preview production build:
   ```bash
   npm run preview
   ```
